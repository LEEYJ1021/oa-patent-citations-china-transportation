# Data

**No record-level data are redistributed in this repository.** The analysis sample is a Lens.org (Scholarly Works) export, which is
governed by The Lens terms of use. This folder documents exactly how to rebuild it and what the pipeline expects.

```
data/
├── README.md                     <- this file
├── DATA_DICTIONARY.md            <- columns the pipeline reads
├── raw/                          <- (git-ignored) Transport_CN_Scholarly_Works.csv, the raw Lens export
├── processed/                    <- (git-ignored) Transport_CN_Scholarly_Works_with_cluster.csv, raw + archived `cluster`
└── synthetic/                    <- generated by `make synthetic`; random values, same layout, for smoke tests only
```

## How the sample was built

| Item | Value |
|---|---|
| Source | Lens.org, Scholarly Works, with links to citing patent documents |
| Query | title/abstract/keyword search for "transportation"; works with >= 1 citing patent; authors at the 33 institutions in Table A1; no year limit |
| Export encoding | MacRoman (raw export); the processed file is read with utf-8-sig / utf-8 / MacRoman / latin-1 fallbacks |
| Raw rows | 13,350 (1,000 empty padding rows, 2 rows without a patent-citation count) |
| After removing 42 missing-year and 4 dated-2026 rows | 12,302 records (10,114 unique Lens IDs) |
| Main analysis window 2003-2024 | 12,020 records = 9,903 unique papers (26 records pre-2003 and 256 dated 2025 excluded) |
| Colour models | 11,955 records (65 with unclassified colour dropped) = 9,846 papers |

Sample construction is tabulated in [`results/primary/sample_flow.csv`](../results/primary/sample_flow.csv) and drawn in Fig. 1.

> **Record the Lens query string and the extraction date** (screenshot or saved query) when you rebuild the export; the paper's Data section needs both.
> Every record has >= 1 citing patent *by construction*; the raw export contains no zero-patent rows. All estimates are therefore intensity
> (intensive-margin) estimates conditional on prior patent citation.

## The `cluster` column (important)

`cluster` (25 research clusters, silhouette 0.364) is an *archived* assignment produced with MiniLM-L6-v2 embeddings -> UMAP -> HDBSCAN.
Re-running the pipeline with current library versions gave a different partition (20 clusters, silhouette 0.244), so the archived labels
must be supplied as a column and are never regenerated inside the analysis. If you cannot obtain the archived labels, results will differ
(clusters are used as fixed effects and as the level of inference, G = 25). The clustering script (`phase0_reconstruct_cluster.py`) is **not** part of
this release; `scripts/figures/make_fig3_umap.py` documents the embedding/UMAP settings used for display.

## Unpaywall cache

`unpaywall_cache.csv` (one row per DOI: `uw_status`, `uw_has_repo`, `uw_versions`, `uw_repo_versions`, `uw_hosts`, `uw_n_repo`) is produced by
`RV_FETCH=1 RV_EMAIL=... python3 step5_full_pipeline.py` (~10k requests, resumable). It is git-ignored; the aggregate cross-tabulation
is in `results/unpaywall/lens_colour_vs_unpaywall_status.csv`. Records whose DOI field contains several DOIs joined by `;` cannot be matched (about 115 records).
